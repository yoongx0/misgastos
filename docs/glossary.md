# Glosario oficial

| Término | Definición |
|---|---|
| **Movimiento** | Registro de dinero que entra (ingreso) o sale (gasto), con monto, categoría, fecha y medio de pago (RN-01). |
| **Gasto / Ingreso** | Tipo del movimiento. Define qué categorías se pueden usar (RN-03). |
| **Centavos** | Unidad en la que se guardan y suman todos los montos. $ 1,00 = 100 centavos (RN-04). |
| **Mes** | Período `AAAA-MM` en hora argentina. Un movimiento pertenece al mes de su fecha (RN-02, RN-05). |
| **Resumen mensual** | Ingresos, gastos, saldo y gastos por categoría de un mes (RN-05). |
| **Saldo** | Ingresos − gastos del mes. Puede ser negativo. |
| **Compra en cuotas** | Gasto con tarjeta de crédito dividido en 2 a 24 movimientos mensuales vinculados (RN-06). |
| **Grupo de cuotas** | Conjunto de movimientos que forman una misma compra en cuotas. Se eliminan juntos (RN-07). |
| **Presupuesto** | Monto mensual máximo que el usuario quiere gastar en una categoría de gasto (RN-08). |
| **Estado del presupuesto** | OK, ALERTA o EXCEDIDO, según el porcentaje gastado en el mes (RN-08). |
| **Hoy** | La fecha actual en `America/Argentina/Buenos_Aires`, nunca la del servidor en UTC (RN-02). |
